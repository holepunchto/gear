bare-svelte

Svelte scaffolding running on Bare, peer-to-peer from day one. Clone directly from peers — no servers required.

Install

gip add git+pear://0.247.9mht63…/bare-svelte
git clone gip::bare-svelte

Usage

Import bare-svelte into your project and mount it the same way you would a vanilla Svelte app. Replication happens in the background via corestore + hyperswarm.
